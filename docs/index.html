標高グリッド リサンプリング比較

nearest（最近傍）vs bilinear（双線形）— 傾斜量図のアーティファクト検証

背景と目的

基盤地図情報の標高グリッドデータは、平面直角座標系（JGD2011 / Japan Plane Rectangular CS VII）から 経緯度系（JGD2011 geographic, EPSG:6668）への変換時に nearest（最近傍）リサンプリングを使用しているという仮説があります。 この処理により、傾斜量図（slope map）にグリッド状の不自然なアーティファクトが生じます。

本ページでは林野庁の0.5mメッシュLiDAR DEM（能登半島）を用い、 nearest と bilinear（双線形）リサンプリング の2種類を比較します。 スライダーを左右に動かすと差異が一目でわかります。

技術的解説

nearest（最近傍）

変換後の各ピクセルに対し、入力グリッドの最も近いピクセル値をそのまま割り当てます。 座標変換で元のグリッドの格子線が斜めになると、その境界が階段状のパターンとして 傾斜量図に現れます。これが「グリッドアーティファクト」の正体です。

bilinear（双線形）

変換後の各ピクセルに対し、入力グリッドの周辺4ピクセルの加重平均を計算します。 補間によって標高値が滑らかに変化するため、傾斜量図でも グリッドパターンのアーティファクトが発生しません。

データ

  • 林野庁 LiDAR 0.5mメッシュDEM（能登半島 2024年）
  • タイル: 07ed58, 07ed59, 07ed68, 07ed69
  • 座標系変換: EPSG:6675 → EPSG:6668
  • 出力解像度: 0.04秒角（1/90000°≈ 1m、基盤地図情報1mDEM相当）
  • 傾斜量: gdaldem slope（度単位、45度飽和グレースケール）

処理ツール

  • GDAL（gdalbuildvrt, gdalwarp, gdaldem, gdal2tiles）
  • MapLibre GL JS（地図表示・スライダー比較）
  • Chart.js（断面図）
